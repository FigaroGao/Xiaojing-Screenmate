# 安装当前页陪看扩展

先解压压缩包。Chrome打开 `chrome://extensions`，Edge打开 `edge://extensions`；开启“开发者模式”，点击“加载已解压的扩展程序”，选择包含manifest.json的xiaojing-browser-extension文件夹。ZIP不能直接拖入安装。

启动电脑Screenmate，右键桌宠复制配对码，在扩展弹窗粘贴；回到要陪看的网页点击开启。电脑端也要开启陪看。浏览器退出后需要重新配对。此扩展不会随压缩包自动安装。

仅提取主动开启的当前页可见文字，不读取输入框；特殊页面、跨域iframe和图片可能无法提取。文字会经平板模型处理，请勿在包含敏感资料的页面开启。
