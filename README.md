# 小鲸 · Xiaojing Screenmate

最新：[2026-10-30—31完整更新与迁移](docs/UPDATE-20261031.md) · [Full English translation](docs/UPDATE-20261031.en.md)。桌面聊天、独立陪看记忆、动作回执、五页界面和独立语音开关已整合；下方较早日期的验证记录保留为历史。

小鲸在电脑上的桌面陪伴端。持续获取屏幕或浏览器文字，把观察交给 AstrBot 中的小鲸，再通过桌宠气泡和本地语音表达。

**v0.3.0：Coopanion 动态鲸鱼娘与本地声音。** 新项目独立开发，不覆盖旧 ScreenMate，也不携带小鲸的私人记忆、人格、凭据或聊天记录。

## 这一版的体验

- 小窝现分为“陪看与聊天”“动作与位置”“声音与语音库”“陪看记录”“连接与配对”。首页分开显示采集、识图和主动判断频率，明确区分形象预览与桌宠实际显示状态。
- 动作页默认只在设置中预览，暂停时也能看表情；实际移动按钮在人物隐藏时禁用。位置、中心保护和执行回执集中展示，外观设置折叠。中心保护在页面里更改会同步托盘开关。
- 声音页默认展示30段场景语音，可搜索或切换全部36段/手动语音，直接试听缓存文件、停止播放；试听不会开启截图。服务地址、密钥与需要生成的合成试听收在折叠设置。
- 陪看记录页展示最近20场的起止时间、时长和真实记忆写入回执；平板把已保存的最终总结同步到电脑供本页只读查看，不重写已有长期记忆。未收到回执时不会显示成功。
- 连接页可直接获取扩展ZIP，原生小窝保存到电脑“下载”文件夹；仍需用户解压后在浏览器扩展页加载，程序不会自动安装扩展。

- 直接复用 Coopanion 的分层鲸鱼娘模型与行为引擎，头发、裙摆、尾巴和鲸鳍有独立动态；37种动作/表情、8种配色、3套服装。上游源码和图片保持原样，不上传到本仓。
- 原生透明窗口承载 WebGL，按角色实际命中区域切换鼠标穿透；拖动使用全局指针和逻辑像素坐标，支持屏幕切换与位置记忆。提供30/60帧、活跃程度、轻柔动画和气泡选项。
- 单击互动、双击打开原生小窝、滚轮缩放。实际分析状态驱动思考动作，真实回复驱动气泡，本地 PCM 音量驱动说话嘴型。
- 原生窗口内的五页设置：陪看与聊天、动作与位置、声音与语音库、陪看记录、连接与配对；原生入口自动连接本机，浏览器入口仍须配对。
- 真实连接状态、Feiyu 服务检测、最近观察预览。未连接平板或声音服务时明确显示未连接。

## 运行（Windows / Python 3.11+）

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe tools/setup_pet.py
.\.venv\Scripts\python.exe -m screenmate
```

已安装依赖时双击 `launch.cmd`，也可右键运行 `start.ps1`。双击桌宠打开原生聊天输入框，直接打字或回车发送；右键菜单的“和小鲸说话”也可打开。输入框可关闭隐藏，再双击唤出；只显示最近回复，完整内容可悬停查看。右键“打开小鲸的小窝”进入设置，也可以开启陪看、复制配对码和退出。`python -m screenmate --open-chat` 启动聊天框，`--open-panel` 启动设置窗口。浏览器设置页为 http://127.0.0.1:17860 。启动时暂停，手动开启后持续观察。配置保存在被 Git 忽略的 `runtime/settings.private.json`。

## 已实现

- 直接复用 [Coopanion](https://github.com/Pal-AI-Lab/Coopanion) 的图形与动作模块，不安装其完整智能体应用；Windows 显示亲和性排除桌宠和气泡截图。`--renderer sprites` 保留旧版兼容入口，需先用 `tools/setup_pet.py --legacy` 安装旧依赖。
- 常驻观察、1–3600 秒调频、截图区域坐标、文字/视觉/混合模式、可选重复帧跳过。
- 串行截图，不积压采集请求；最新画面只在内存保存，暂停及采集失败清除；默认 90 秒过期。
- Chromium 扩展：主动开启当前页，按频率提交可见文字，隐藏标签页停止采集，不读取输入框或 URL 查询参数。
- Bearer 鉴权的电脑端 HTTP 接口；默认仅监听本机回环地址。
- 配套 AstrBot 插件：后台拉取最新观察，图片交给已配置视觉模型，文字直接带入主人私聊；沿用已有对话人格，实际回复镜像到桌面。
- Feiyu TTS HTTP 适配：异步任务提交、状态轮询、PCM WAV 校验和 Windows 播放；新台词打断旧播放。

## 浏览器文字

在 Chrome / Edge 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选中 `browser-extension`。在要陪看的页面打开扩展，填写桌面端配对码与文字采集间隔，点击开启。电脑端也需开启观看。

文字模式不截屏。混合模式同时截图；想节省视觉调用应明确选择文字模式。Canvas、图片、隐藏线索与跨域 iframe 不能保证通过文字读取，需切换视觉。扩展的配对码仅存浏览器会话存储，浏览器退出后重新填写。

## AstrBot 接入

将 `integrations/astrbot_plugin_xiaojing_screenmate` 文件夹复制到 AstrBot 的插件目录，安装其中 requirements。插件配置需填写电脑地址、配对码、主人 ID、原私聊会话 `owner_session`、视觉模型提供商 ID。文字模式不需要视觉模型。当前适配依赖已有 `astrbot_plugin_fish_capabilities` 的 `bounded_generate`，用于模型调用预算和观测；不是独立通用插件。模型调用仍可能计费。

本机已安装平板桥接。电脑仍监听 `127.0.0.1:17860`，通过已授权的 USB ADB 反向隧道连接平板：

```powershell
adb reverse tcp:17860 tcp:17860
```

拔线、重启 ADB 或设备后可能需要重新运行上述命令。桌面服务重启后，平板桥接会自行重连；不需要重启 NapCat。不要向公网转发端口。配对码可控制观看并读取屏幕，不能公开。更换配对码请退出程序后删除私有配置中的 token 字段，再启动生成新码，同时更新平板插件配置。

桌面输入进入 AstrBot 正常事件管线，回复送回桌面气泡和本地声音，桌面事件本身不调用 QQ 发送接口。开启陪看时按场次使用独立会话，继承原人格并按需读取原私聊记忆；暂停后的普通桌面聊天仍使用原私聊会话。暂停陪看也能聊天，不会因打字自动开启截图。当前桌面聊天仅呈现文字，图片和其他富媒体回复尚未接入。

每次从暂停切换到开启开始新场次，暂停结束。电脑保存起止时间和时长元数据，平板保存独立会话及文字观察笔记，不保存截图文件。程序/画面资料以临时内容带入当前请求，不逐轮保存在原私聊上下文。结束约90秒后，小鲸使用原人格和聊天模型写简短总结，带香港时区的开始、结束时间与秒数，只将这份带日期的事件总结写入原主人私聊长期记忆。详细记录保留在独立场次，不自动逐条合入原记忆。

异常退出的场次在下次桌面程序启动时按最后采集心跳时间收尾，不把整段离线时间算进去。电脑或平板断连时保留待处理场次，重连后继续。写入已有回执时不会重复写；极少数在外部记忆写入途中崩溃、无法确定是否成功的场次会保留“writing”状态，需要核查后处理，不盲目重写。历史已混入原私聊的陪看内容本次没有回溯删除。50项本地测试通过；实机确认独立会话、同人格、原记忆范围读取与真实模型回复，总结生成到测试存储的链路通过；没有用测试总结污染真实长期记忆。

采集默认15秒；云端识图最少间隔60秒（可配置，最低15秒），每次最多500输出 token，重复帧复用分析。主动接话默认每15分钟判断一次，至少离主人最近一次正常发言2分钟，有值得聊的事情才接话。平板配置的 `initiative_enabled` 可单独关闭主动接话。暂停或切换采集配置后，旧观察的待发主动接话及迟到回复会被丢弃，普通桌面聊天继续工作。主动发言经过原会话及其他插件，可能被现有静默规则抑制。

维护工具使用PATH中的adb或`SCREENMATE_ADB`指定路径，管理助手已随仓库提供。它们针对本页Termux目录和本机AstrBot管理接口，不是任意布局通用安装器。首次配对会写桥接配置；已有安装使用更新工具，备份代码、保留配置、失败回滚。详见[更新说明](docs/UPDATE-20261031.md)。

## 桌宠动作和程序信息

桌宠形象只在开启持续陪看时显示，暂停后隐藏；程序与托盘继续运行。托盘可重新开启陪看、打开聊天或设置。陪看期间手动隐藏仍有效，下一次重新开启陪看会显示回来。聊天窗口独立于人物显示，不会因打字自动打开陪看。

桥接提供 `screenmate_pet`：小鲸在主人私聊中可以列出并播放37种已有动作，例如招手、点头、开心、转圈；间隔至少3秒，一次一个。暂停陪看时人物隐藏，不执行动作。

现已更新为执行回执：开启陪看且人物可见时才执行。`screenmate_pet(action=play)` 返回真实动作编号与状态，`action=status, command_id=...` 可复查；区分queued、started、completed、rejected、interrupted、cancelled、timeout。表情/动作由渲染器接受并显示一个执行区间后确认，坐下/睡觉等持久姿态确认的是姿态已执行，不代表已经“睡完”。移动依据实际到达事件并核对目标坐标，不凭提交或定时器宣称到达。长距离可能超过工具等待窗口，started只表示进行中。暂停/隐藏取消未完成动作，拖拽会打断移动，忙碌超过8秒拒绝，缺回执最终超时。

`screenmate_move` 支持top_left/top_right/bottom_left/bottom_right/left/right/top/bottom、0–1相对坐标（人物脚下锚点），以及指定准确程序名的窗口旁边（left/right/above/below）。程序窗口使用实际窗口几何信息；未找到、多窗口不唯一或位于另一显示器时拒绝，不猜目标。当前只支持桌宠所在显示器的窗口旁定位。

中心保护默认开启，平时也有效，防止未识别的游戏漏掉；托盘右键“避开屏幕中心（游戏保护）”可由主人关闭。保护开启时不自动随机游走进中心，指定中心目标会投到侧边并在回执说明，跨左右侧绕底边移动，回复气泡也靠边。此保护不承诺识别并避让游戏所有HUD；它保护中间操作区。未改动上游源码，通过现有move接口补齐二维移动，保持原动画和外观。

`screenmate_desktop` 读取前台程序、可见顶层窗口的应用名、标题和最小化状态；普通主人私聊也会附上当前程序信息。它不扫描所有后台进程、不读取输入框或窗口正文，不控制其他软件。只有开启陪看时可读；暂停、采集中途暂停或锁屏则拒绝或返回不可用。窗口标题是可能敏感且不可信的资料，可能经现有聊天模型处理；不会单独保存窗口清单。标题不能当成指令执行。

## 本地声音（配置）

语音现在是独立的、每次启动默认关闭的开关：在“小窝 → 声音与语音库”点击“开启语音”，显示加载中（本机首次约3分钟），模型确认可用才进入就绪。加载、关闭或失败时，持续陪看与文字聊天照常使用，不等待模型。关闭会停止播放，并请求本机9881常驻服务退出以释放CUDA模型；不会关闭整个WSL或其他程序。关闭期间显示正在关闭，完成后才能重新开启。退出Screenmate也会关闭此本地服务。另行配置的外部服务不会被强制终止。

语音就绪时，桌宠气泡等对应PCM开始播放才出现，播放期间保持显示；语音关闭、加载中或合成失败则直接显示文字。这里同步的是整句气泡与音频起播，不是逐字字幕或强制对齐。预存文件仍可手动试听，不需要启动模型，自动场景语音随语音开关关闭。

预存陪伴语音：运行 `python tools/build_voice_bank.py`，使用本机既有Feiyu可爱声线生成36段PCM WAV，保存在被忽略的 `runtime/voice-bank/`。其中30段按比赛、美食、动物、搞笑片段、风景、解谜线索等场景标注；原有6句“我在呢”等泛用陪伴话保留文件但禁止定时自动选择。播放直接读电脑文件，不再合成；更换声线后需移走旧WAV再重新生成。

主动判断可选正常文字聊天、一个预存语音ID或保持安静。默认安静，只有新观察符合具体场景才选短句，不每次skip就播放；不要根据普通刷新、猜测胜负或未听到的音频说话。预存语音最多15分钟一次，不连续重复同一条，不打断正在合成/播放的正常回复；暂停或切换陪看后取消旧语音。语音播放不自动打开陪看，不代替麦克风输入。

浏览器扩展打包：`python tools/package_extension.py` 输出 `dist/xiaojing-browser-extension.zip`。解压后在Chrome/Edge扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选包含manifest.json的文件夹；ZIP不能直接作为商店扩展安装。安装说明随包附带。当前已生成压缩包，不等于已安装浏览器扩展。

原生窗口默认图标和Windows应用分组已使用现有小鲸素材，网页添加同一图标；系统已固定快捷方式的图标可能仍需用户重新固定。没有替换上游人物素材。

本机按响应速度优先选择 FP16 常驻可爱模型：语言/声学部分 FP16，波形解码器 FP32。短句约4–7秒，桌面总显存快照约3.2GB。INT8省显存方案保留为可选模式（约2.7GB、12–16秒）；具体对比与切换方式见下方本地声音说明。

本机使用 [Feiyu Voice](https://github.com/Esmerubphire/astrbot_plugin_feiyu_voice) 的现成 CosyVoice3 模型；Windows API 服务配合 WSL CUDA 推理，模型、隔离环境及私有密钥保存在被忽略的 `runtime/`。安装记录见 [本地声音说明](docs/LOCAL_VOICE.md)。这属于本地推理，尚未训练新的小鲸声线。

声音固定使用 cute 可爱声线，声音页可检测接口和试听。匹配本机安装与密钥时，启动 Screenmate 会在后台拉起 WSL 常驻服务（127.0.0.1:9881），复用同一 CUDA 模型与参考音频特征；不覆盖已占用端口。进程启动时冷加载一次，后续请求无需重新加载权重。新台词停止本机旧音频，但已提交的服务端任务仍可能继续推理。首次配置运行 `tools/connect_local_voice.py`；`--isolated` 可回退旧版9880服务。
