# 产品与实施记录

## 2026-10-30 / Chibi Days · v0.2

用户反馈首版粗糙，并明确希望 Q版、生动。接入现成 `dsh-pet-dafeiyu` 的18姿态，继续复用现有桌宠引擎，未重画角色。增加呼吸眨眼、姿态轻晃/小跳、单击/连续戳戳反馈、悬停挥手、闲置小动作、活泼模式短距离散步及滚轮缩放。动作优先级为显式互动/拖拽、语音说话、闲置表现；本地动作不向QQ发消息或调用模型。

新增原生小窝窗口，自动连接自己的本机服务；浏览器入口保留配对。四个页面分开管理陪看、桌宠外观、声音与连接。外观设置不会清除观察或唤醒截图；服务状态来自真实心跳和检测。维持平板、声音模型和自主接话未验收的边界。

## 2026-10-30 / First Light

目标：让小鲸在电脑桌面上持续陪看，手动控制截图到视觉模块的频率；网页和文字 ARG 可绕过视觉；使用本地 Feiyu 语音；桌宠表现沿用真实小鲸，不另建人格。

首版结构：Windows 核心采集 + 本机控制页 + 现有 dsh-co-pet 桌宠适配 + Chromium 可见文字扩展 + AstrBot 观察适配插件 + 独立 Feiyu HTTP 客户端。按用户要求移除自绘桌宠，直接复用现有实现。

截图、视觉理解与说话分别处理：电脑负责采集；AstrBot 插件拉取最新帧并串行视觉识读，处理中产生的新帧合并为最新帧；主人的已有对话收到最新有效观察。观察周期不等于发言周期。

## 下一阶段

1. 与实际平板上的 AstrBot 版本及小鲸能力插件做兼容性验证，确认事件顺序、人格与现有视觉调用复用。
2. 将桌面输入和主动接话接入同一小鲸会话，保留对话上下文，分别控制观察与接话频率；支持静默观看。
3. 本机部署 Feiyu 服务并对两种声线试听、测显存与游戏资源竞争；训练新声音单独管理数据与模型。
4. 浏览器端配合真实 ARG 验证文字提取、图片回退和线索上下文；窗口选择器替代区域坐标输入。
5. 桌宠素材包清单、动画状态、缩放、点击穿透、摸头事件与可替换角色；逐个核对素材授权。
6. 受认证加密连接、可靠配对撤销、桌面启动快捷方式与打包安装。
