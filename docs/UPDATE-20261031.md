# 2026-10-30—31：桌面聊天、陪看记忆、动作与声音

[中文](UPDATE-20261031.md) | [English — 完整翻译](UPDATE-20261031.en.md)

本仓库仅维护电脑Screenmate与其AstrBot桥接。QQ/B站/课程等通用能力仍在[astrbot-fish-capabilities](https://github.com/FigaroGao/astrbot-fish-capabilities)。两者分别安装，不将用户的运行数据、模型或角色素材上传GitHub。

## 本次功能

- **桌面聊天**：双击角色或用托盘“和小鲸说话”打开原生输入框，支持回车发送、失败保留草稿和最新回复。暂停陪看时仍可聊天，输入不自动截图。文字走原AstrBot人格；桌面回复不调用QQ发送接口。`--open-chat`直接打开输入框，`--open-panel`打开小窝。
- **独立陪看记忆**：开启／暂停划分场次，保存实际起止与时长。陪看使用独立会话，继承原人格并按原主人范围召回记忆；画面和程序信息只临时注入。结束约90秒后由小鲸写一份带日期、时长的总结进原长期记忆，详细笔记留在独立场次。异常退出按最后心跳收尾，不把离线时间算进去；外部写入结果不确定时保留待核查，不盲目重复写。
- **桌面信息**：开启陪看时可读取前台程序、可见顶层窗口与最小化状态；不扫描所有后台进程、不读输入框或窗口正文，锁屏／暂停不可读。
- **动作与位置**：现有动作增加ID和执行回执，排队不等于播放完成。支持角落、边缘、相对坐标及同屏程序窗口旁；不存在、跨屏或不唯一的窗口拒绝猜测。中心保护默认开启，跨侧绕底部走，气泡靠边；不承诺避开所有游戏HUD。拖动打断移动，暂停／隐藏取消旧动作。
- **显示与闪烁修补**：人物只在持续陪看开启时出现，托盘和聊天可继续使用。移除每帧变更窗口mask的路径，改为渲染就绪后使用稳定透明表面；尚未宣称所有显卡、游戏和缩放组合的间歇闪烁已彻底消失。
- **预存语音**：36段本地PCM，30段按具体场景供自动选择，6段泛用陪伴话仅供手动试听。默认安静，不因每次不发文字就播声音；有场景匹配、冷却和过期检查，不打断正常回复。文件留在runtime，不上传录音。
- **独立语音开关**：每次启动默认关闭本地语音模型。小窝点击开启后后台加载，显示关闭／加载中／就绪／关闭中／失败，真正可用才说话；加载不阻塞文字或陪看。可途中取消；关闭或退出请求本机常驻服务退出释放CUDA，不关闭整个WSL或别的程序。原FP16声线保留，外部服务不强杀。
- **气泡起播同步**：语音就绪时，整句气泡等对应PCM开始播放才出现，播放期间保留；关闭、加载或合成失败时直接文字。不是逐字字幕或强制音素对齐。预存语音可在不加载模型时手动试听。
- **五页小窝**：陪看与聊天、动作与位置、声音与语音库、陪看记录、连接与配对。显示实际采集／云端识图／主动判断频率、动作回执、记忆写入状态和最终总结；动作默认只预览。语音库支持搜索、筛选、试听与停止。
- **浏览器扩展**：连接页下载ZIP，原生窗口保存到系统“下载”文件夹。仍需本人解压、在浏览器扩展页开启开发者模式并加载已解压文件；不会自动安装。只在主动开启的页面提取可见文字。

## 安装与更新

双击`launch.cmd`启动，用托盘打开小窝；启动默认暂停截图、关闭语音。保留`runtime/settings.private.json`等私有数据。先安装README依赖并运行素材安装器；模型、人物资源和运行时数据库均不随源码分发。

已有平板桥接更新需包含目录内全部Python文件（含`watch_memory.py`），保留原配置再重载桥接。主能力插件与桥接都需要按自己的主人ID、会话和模型配置。USB使用`adb reverse tcp:17860 tcp:17860`，仅回环访问，不开放公网或局域网端口。

维护工具现自带`tools/tablet_api_helper.py`，不依赖维护者电脑的外部脚本路径。把adb放入PATH或设置`SCREENMATE_ADB`为完整路径；可用`SCREENMATE_TABLET_API_HELPER`覆盖助手文件。`tools/connect_tablet.py`仅用于首次配对，会写桥接配置；已有安装使用`tools/update_tablet_bridge.py`备份、更新并在失败时回滚。这些助手针对README所述Termux目录和本机AstrBot管理接口，其他布局需调整，不是任意设备通用安装器。配对码和语音Key只存本机。

## 验证与尚未确认的部分

66项本地测试通过，包括独立场次、权限边界、回执状态、真实ffmpeg以外的桌面逻辑、语音开关取消／重试和模拟PCM起播。没有把排队回执当动画完成。

参考设备实测：真实桌面输入获得原人格模型回复；独立场次最终总结写入原记忆并核对回执；原生WebEngine动作完成、移动到达与人为打断；五页界面、默认预览与扩展下载。语音FP16实机完整加载216秒，关闭后进程退出，加载途中取消也成功；此开关验收没有播放测试声音或开启截图。

仍需日常观察：真实模型自主挑选动作／短语音的自然程度、偶发闪烁、音频与气泡的主观同步感、全屏游戏与实体多屏混合缩放。未自动安装扩展，也未把所有网页兼容性当作已验证。端口、队列和本地服务收到请求不等于整个链路成功。
